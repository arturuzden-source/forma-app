- Три ответа `bad_json` — следствие слишком низкого предела длины ответа (у рассуждающих моделей в него входят токены рассуждения). Исправлено: пределы подняты, обрезанный ответ распознаётся как `truncated`.

- Все ответы укладываются в цель 45 секунд.
- **Потрачено на проверку: 0,0407 $.** Оценка месяца по измеренным токенам (30 обращений в день + еженедельные планы): около 0,10 $; бюджет 5 $ с большим запасом. Фото и фоновые операции оцениваются на этапе 5.

## Ограничения и необходимые действия

1. **Тариф Railway.** Предел памяти 1 ГБ и диска 500 МБ соответствуют пробному тарифу с разовым кредитом. До его исчерпания нужен Hobby, иначе сервис остановится. Это же нужно для увеличения диска под фото.
2. **Независимая копия.** Выбрать хранилище вне Volume (Cloudflare R2 или Railway Bucket), затем настроить шифрование и выгрузку.
3. **Короткая пауза при обновлении.** Сервис с Volume не запускает две версии одновременно: несколько секунд недоступности при каждом обновлении. Для пилота допустимо.
4. **Запуск через npm.** `npm start` не передавал SIGTERM, и корректная остановка не срабатывала. Команда запуска на Railway изменена на `node dist/server/index.js`.
5. **Автообновление** требует установленного приложения Railway App на GitHub, одной авторизации недостаточно.

## Критерий 25 — новая формулировка

Интерфейс и API работают в одном сервисе Railway, поэтому критерий касается потери связи во время работы приложения:

> Если API становится недоступен во время работы мини-приложения (сбой, обновление сервиса, обрыв сети), интерфейс не позднее чем через 10 секунд показывает сообщение «Нет связи с сервером», блокирует действия, требующие сохранения, показывает ранее загруженные данные только для чтения с датой загрузки и автоматически повторяет подключение каждые 30 секунд. Несохранённые действия не показываются как сохранённые. Кэш привязан к Telegram ID и не показывается другому пользователю.
>
> **Проверка:** открыть приложение и дождаться загрузки данных → включить авиарежим → убедиться, что появилось сообщение, кнопка записи недоступна, данные видны с датой загрузки → выключить авиарежим → не позднее чем через 30 секунд данные обновились, запись снова доступна.
>
> Если сервис полностью остановлен до открытия приложения, Telegram показывает ошибку загрузки страницы; для личного пилота это допустимо.

## Запуск, остановка, восстановление

Подробно — [operations.md](operations.md). Кратко:

- **Обновить:** push в `main`.
- **Перезапустить:** Railway → forma-app → Deployments → Restart.
- **Откатить:** Railway → Deployments → предыдущее успешное → Rollback. Данные на Volume сохраняются.
- **Восстановить из копии:** задать переменную `RESTORE_FROM=ГГГГ-ММ-ДД`, дождаться перезапуска, проверить данные, удалить переменную.
- **Состояние:** команда `/status` в боте.
