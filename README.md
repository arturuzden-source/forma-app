# Forma

Telegram Mini App — персональный помощник по тренировкам, питанию и прогрессу.

Личный пилот. Рабочее приложение работает на Railway, код хранится в этом приватном репозитории.

Секреты (токен бота, ключ ИИ) хранятся только в переменных окружения Railway и никогда не попадают в репозиторий.
